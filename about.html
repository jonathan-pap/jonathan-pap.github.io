This site is a static blog for GitHub Pages. Posts are written in Markdown under content/posts/ and registered in content/posts.json.

Publishing workflow

  1. Create content/posts/my-post.md
  2. Add an entry with "slug": "my-post" in content/posts.json
  3. Commit + push to GitHub
