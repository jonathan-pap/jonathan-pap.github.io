This is a static blog hosted on GitHub Pages. Articles are written in Markdown under content/posts/ and registered in content/posts.json.

How to publish a new post

  1. Create content/posts/my-new-post.md
  2. Add a matching entry with "slug": "my-new-post" in content/posts.json
  3. Push to GitHub → GitHub Pages updates automatically
