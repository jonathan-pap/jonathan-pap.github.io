Use it on your other device

  1. Open this page there. Sign in to claude.ai with the same account and open this page's link: it's private to you, so it works on any device you're signed in on. To open it from a different account, use this page's Share menu first.
  2. Copy the starter site. On the Starter site tab, press Copy the website code.
  3. Save it as a file. Paste it into a plain text editor and save it as index.html. The Publish tab shows how on Windows and Mac.
  4. Make it yours. Everything to change is in [square brackets]. Search for [ and work down the page.
  5. Put it online. Free, with GitHub Pages or Netlify. Steps on the Publish tab.
  6. Want more? Paste the Prompt for Claude into a chat on that device, together with your index.html, and keep building.

Design system

Colours

Deep navy for the ground, gold for the one thing you want people to notice, blue only for the soft glow.

Type

  • Figtree 800 for headings, set tight (letter-spacing −0.02em).
  • Figtree 400 and 600 for body text, 17px with generous line height.
  • IBM Plex Mono 500 in capitals with wide spacing for small labels, chips and dates.

Both are free Google Fonts. The starter site already links them.

The people-bars

A bar chart made of people: seven bars with round heads, rising left to right, joined by a thin line through the heads. Gold on navy for heroes; blue bars with gold dots when it sits behind text.

  • Never fade gold with opacity on navy: it turns murky olive. Use the blue "ghost" version instead.
  • Keep the dot grid faint (white at about 5%) and the glow soft (blue at 30%).
  • One bold thing per screen: if the people-bars are there, keep everything else quiet.

Make it yours

      
    
        
  • Fill the brackets. Search for [: your name, your intro, three case studies, your links.
    • 
        
  • Drop what you don't need. Each part of the page is one <section> block; delete the whole block.
    • 
        
  • Add your photo. Replace <div class="avatar">[YN]</div> with <img class="avatar" src="me.jpg" alt="[Your Name]"> and put me.jpg next to the file.
    • 
        
  • Change the accent. Edit --gold and --gold-light at the top of the file; everything follows.

Publish it

    

      

        
1 · Just look at it

        
    
          
  • Windows: open Notepad, paste, then File › Save as. Name it index.html, set "Save as type" to All files and encoding to UTF-8.
    • 
          
  • Mac: open TextEdit, choose Format › Make Plain Text, paste, and save as index.html.
    • 
          
  • Double-click the file. It opens in your browser.
    • 
        

      

      

        
2 · GitHub Pages (free, permanent)

        
    
          
  • Create a free account at github.com.
    • 
          
  • Make a new public repository named exactly yourusername.github.io.
    • 
          
  • Choose Add file › Upload files, drop in index.html, and press Commit changes.
    • 
          
  • After a minute or two the site is live at https://yourusername.github.io.
    • 
        

      

      

        
3 · Netlify Drop (fastest)

        
    
          
  • Put index.html (and any images) in a folder.
    • 
          
  • Go to app.netlify.com/drop and drag the folder onto the page.
    • 
          
  • It's online in seconds. Sign up (free) to keep it and choose a nicer address.
    • 
        

      

    

    

      
Your own domain

      
Both GitHub Pages and Netlify let you connect a domain you own, such as yourname.com, from the site's settings. Buy the domain from any registrar, then follow their "custom domain" steps.
